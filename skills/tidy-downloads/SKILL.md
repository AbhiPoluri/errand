---
name: Tidy Downloads
description: Sort the Downloads folder into subfolders by file type
when_to_use: the user asks to clean up, organize, or tidy their Downloads
---

1. List what's in the Downloads folder.
2. Group the files by kind — Images, Documents, Installers/Archives, Audio, Video, and a catch-all "Other".
3. Make a subfolder for each group that actually has files (skip empty groups).
4. Move each file into its group's folder. Keep every move reversible.
5. At the end, say how many files moved into which folders, and mention anything you left where it was.
